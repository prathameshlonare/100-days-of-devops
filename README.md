# Prathamesh's 100-Day DevOps & Cloud Journey

Welcome to my personal 100-Day DevOps & Cloud Journey repository! 👋

I'm **Prathamesh Lonare**, an Associate DevOps / Cloud Engineer (B.Tech CSE '26) currently focusing on AWS Serverless, Terraform, Docker, and CI/CD. 

Unlike generic "100 Days of Code" templates, this repository is a **highly tailored, personalized curriculum** designed specifically around my existing skills, my past projects, and my targeted career goals (Cloud Support Engineer, Junior DevOps Engineer, etc.).

## 🎯 The Goal
To build deep, hands-on troubleshooting skills, master cloud infrastructure, and document my daily progress as I prepare for my first full-time role in Cloud/Infrastructure.

## 🛠️ My Existing Stack & Projects
Before starting this journey, I had already built several serverless applications. This 100-day curriculum specifically builds *upon* these foundations rather than starting from scratch:

- **Student Accommodation Finder**: AWS Lambda, API Gateway, DynamoDB, CloudFormation, CloudWatch, Python.
- **Online Voting System**: AWS Lambda, IAM, DynamoDB, Cognito, CloudWatch, S3, GitHub Actions.
- **Sysadmin Toolkit**: Bash scripting.

## 📖 How This Journey Works
This journey follows a strict **BUILD → BREAK → TROUBLESHOOT → FIX → DOCUMENT → CLEANUP** philosophy. 

Every single day logged in the `01-daily-posts/` directory includes:
1. **Fresh-Start Build**: Provisioning infrastructure from scratch in AWS (`eu-north-1`).
2. **Intentional Breakage**: Breaking the system to observe symptoms.
3. **Troubleshooting Record**: Documenting the Root Cause Analysis (RCA) and the fix.
4. **Cleanup**: Tearing everything down to leave a $0 billing footprint.
