## 📖 How This Journey Works
Every single day follows a strict **BUILD → BREAK → TROUBLESHOOT → FIX → DOCUMENT → CLEANUP** philosophy. 

Inside each daily folder, you'll find:
1. **Fresh-Start Build**: Provisioning infrastructure from scratch in AWS (`eu-north-1`).
2. **Intentional Breakage**: Breaking the system to observe symptoms.
3. **Troubleshooting Record**: Documenting the Root Cause Analysis (RCA) and the fix.
4. **Cleanup**: Tearing everything down to leave a $0 billing footprint.
