## Part 2: Listing Processes with ps (20 min)

### The Problem

Something is wrong. A process is using too much memory. How do you find it?

### The Command

```bash
ps aux
```

| Flag | What it does |
|------|--------------|
| `a` | Show processes from all users |
| `u` | Show user/owner |
| `x` | Include processes without a terminal |

### Output

```
USER       PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
root         1  0.0  0.1 168892 11000 ?        Ss   Jun30   0:30 /sbin/init
www-data   567  2.3  1.5 234567 67890 ?        Sl   Jun30  12:45 nginx: worker
prathamesh 1234 0.0  0.0  21532  3560 pts/0    Ss   08:00   0:00 bash
```

| Column | Meaning |
|--------|---------|
| USER | Who owns the process |
| PID | Process ID (use this to kill it) |
| %CPU | CPU usage |
| %MEM | Memory usage |
| RSS | Physical memory (KB) |
| STAT | State (S=sleeping, R=running, Z=zombie) |
| COMMAND | What command started it |

### Sort by CPU or Memory

```bash
# Sort by CPU (top consumers first)
ps aux --sort=-%cpu | head -10

# Sort by memory (top consumers first)
ps aux --sort=-%mem | head -10
```

### Find a Specific Process

```bash
ps aux | grep nginx
ps aux | grep python
ps aux | grep prathamesh
```

### Try It

```bash
ps aux | head -10
ps aux --sort=-%cpu | head -5
ps aux --sort=-%mem | head -5
ps aux | grep bash
```

### Exercise 1

1. Run `ps aux | head -10` — list top processes
2. Run `ps aux --sort=-%cpu | head -5` — top 5 CPU consumers
3. Run `ps aux --sort=-%mem | head -5` — top 5 memory consumers
4. Run `ps aux | grep $$` — find your own shell

## Part 3: Real-Time Monitoring with top/htop (15 min)

### top — Built-in Monitor

```bash
top
```

This shows live process info, updating every 3 seconds.

| Key | Action |
|-----|--------|
| `q` | Quit |
| `M` | Sort by memory |
| `P` | Sort by CPU |
| `k` | Kill a process (enter PID) |
| `1` | Show per-CPU stats |

### htop — Better Version

```bash
htop
```

If installed, `htop` is `top` with colors and mouse support. Easier to read.

- Arrow keys to scroll
- `F9` to kill a process
- `F6` to sort
- `F10` to quit

### Try It

```bash
top -n 1 | head -20
# Or if htop is installed:
htop
```

### Exercise 2

1. Run `top` — watch for 10 seconds, identify the top CPU consumer
2. Run `htop` if available — sort by memory (press `M`)
3. Press `q` to quit

## Part 4: Killing Processes (15 min)

### The Problem

A process is stuck. It's using 100% CPU. You need to stop it.

### kill — Kill by PID

```bash
kill PID            # Send SIGTERM (graceful shutdown)
kill -9 PID         # Send SIGKILL (force kill)
kill -15 PID        # Send SIGTERM (same as no flag)
```

| Signal | What it does |
|--------|--------------|
| `SIGTERM` (15) | Graceful shutdown — let the process clean up |
| `SIGKILL` (9) | Force kill — immediate, no cleanup |
| `SIGHUP` (1) | Reload config (for services that support it) |

**Always try `kill PID` first (SIGTERM).** Only use `kill -9` if SIGTERM doesn't work.

### pkill — Kill by Name

```bash
pkill nginx         # Kill all nginx processes
pkill -9 python     # Force kill all python processes
```

### killall — Kill All Matching

```bash
killall nginx       # Kill all nginx processes
killall -9 python   # Force kill all python
```

### Try It

```bash
# Start a background process
sleep 1000 &
sleep 1000 &

# Find it
ps aux | grep sleep

# Kill it
kill $(pgrep sleep)

# Verify
ps aux | grep sleep
```

### Exercise 3

1. Run `sleep 1000 &` — start a background process
2. Run `ps aux | grep sleep` — find its PID
3. Run `kill PID` — graceful kill
4. Run `ps aux | grep sleep` — verify it's gone

## Part 5: Managing Services with systemctl (15 min)

### The Problem

Your web server crashed. How do you restart it? How do you make it start on boot?

### systemctl — The Command

```bash
systemctl status nginx        # Check status
systemctl start nginx         # Start service
systemctl stop nginx          # Stop service
systemctl restart nginx       # Restart service
systemctl reload nginx        # Reload config (no downtime)
systemctl enable nginx        # Start on boot
systemctl disable nginx       # Don't start on boot
systemctl status nginx        # See if running
```

### Try It

```bash
systemctl status sshd
systemctl status nginx
systemctl list-units --type=service --state=running
```

### Exercise 4

1. Run `systemctl status sshd` — is SSH running?
2. Run `systemctl list-units --type=service --state=running` — all running services
3. Run `systemctl status nginx` — is nginx installed?

## Part 6: Background Jobs (5 min)

### Run in Background

```bash
long-running-command &      # Run in background
nohup long-running-command &  # Run immune to hangups
```

### Manage Background Jobs

```bash
jobs                        # List background jobs
fg %1                       # Bring job 1 to foreground
bg %1                       # Resume job 1 in background
```

### Try It

```bash
sleep 100 &
jobs
fg %1
# Press Ctrl+Z to suspend
bg %1
jobs
```

### Exercise 5

1. Run `sleep 100 &` — background job
2. Run `jobs` — see it listed
3. Run `fg %1` — bring to foreground
4. Press `Ctrl+Z` — suspend
5. Run `bg %1` — resume in background

## Part 7: Build Task — process-manager.sh (20 min)

### Create the File

```bash
cd devops-journey/sysadmin-toolkit
nano process-manager.sh
```

### Write This Script

```bash
#!/bin/bash

# process-manager.sh — Monitor and manage processes
# Usage: ./process-manager.sh [command] [args]

case "${1:-help}" in
    top-cpu)
        echo "=== Top 10 CPU Consumers ==="
        ps aux --sort=-%cpu | head -11
        ;;
    top-mem)
        echo "=== Top 10 Memory Consumers ==="
        ps aux --sort=-%mem | head -11
        ;;
    find)
        if [ -z "$2" ]; then
            echo "Usage: $0 find <process-name>"
            exit 1
        fi
        echo "=== Processes matching: $2 ==="
        ps aux | grep "$2" | grep -v grep
        ;;
    kill)
        if [ -z "$2" ]; then
            echo "Usage: $0 kill <PID>"
            exit 1
        fi
        echo "Killing PID $2 with SIGTERM..."
        kill "$2" 2>/dev/null
        if [ $? -eq 0 ]; then
            echo "Process $2 terminated"
        else
            echo "Failed to kill PID $2 (may need sudo or PID doesn't exist)"
        fi
        ;;
    force-kill)
        if [ -z "$2" ]; then
            echo "Usage: $0 force-kill <process-name>"
            exit 1
        fi
        echo "Force killing all processes matching: $2"
        pkill -9 "$2" 2>/dev/null
        echo "Done"
        ;;
    services)
        echo "=== Running Services ==="
        systemctl list-units --type=service --state=running --no-pager
        ;;
    zombies)
        echo "=== Zombie Processes ==="
        ps aux | awk '$8 ~ /Z/ {print $0}'
        COUNT=$(ps aux | awk '$8 ~ /Z/' | wc -l)
        echo ""
        echo "Found $COUNT zombie processes"
        ;;
    help|*)
        echo "process-manager.sh — Process Management Tool"
        echo ""
        echo "Usage: $0 [command]"
        echo ""
        echo "Commands:"
        echo "  top-cpu          Show top 10 CPU consumers"
        echo "  top-mem          Show top 10 memory consumers"
        echo "  find <name>      Find processes by name"
        echo "  kill <PID>       Kill process by PID (graceful)"
        echo "  force-kill <name> Force kill by name"
        echo "  services         Show running services"
        echo "  zombies          Find zombie processes"
        echo "  help             Show this help"
        ;;
esac
```

### Make It Executable

```bash
chmod +x process-manager.sh
```

### Test It

```bash
./process-manager.sh top-cpu
./process-manager.sh top-mem
./process-manager.sh find bash
./process-manager.sh zombies
./process-manager.sh help
```

### What You Just Built

A process management toolkit. Use it to diagnose and fix issues on any Linux server.

## Part 8: Recap (5 min)

### What You Learned

| Command | Use Case |
|---------|----------|
| `ps aux --sort=-%cpu` | Find CPU hogs |
| `ps aux --sort=-%mem` | Find memory hogs |
| `top` / `htop` | Real-time monitoring |
| `kill PID` | Graceful kill |
| `kill -9 PID` | Force kill |
| `pkill name` | Kill by name |
| `systemctl status svc` | Check service status |
| `systemctl restart svc` | Restart service |

### The Pattern

When something is wrong:
1. `ps aux --sort=-%cpu | head -10` — find the CPU hog
2. `ps aux | grep <name>` — find specific process
3. `kill PID` — try graceful kill first
4. `kill -9 PID` — force if needed
5. `systemctl restart <service>` — restart the service
6. `systemctl status <service>` — verify it's running
