# Day 2/100 — Linux File System

> **Goal:** Understand the Linux directory structure so you always know where to find configs, logs, binaries, and user data. You'll explore the real file system and build a reference map.

## Part 1: Why the File System Matters in DevOps (10 min)

Every server you'll ever manage runs Linux. Every config file lives in `/etc`. Every log lives in `/var/log`. Every process shows up in `/proc`.

If you don't know the map, you're lost.

### What We'll Cover

| Command | What it does |
|---------|--------------|
| `ls` | List directory contents |
| `tree` | Visualize directory structure |
| `du` | Check directory size |
| `file` | Identify file types |
| `stat` | View detailed file metadata |
| `cat` | Read file contents |

## Part 2: The Top-Level Directories (20 min)

### The Problem

You SSH into a server. Where do you look for:
- The nginx config?
- The application logs?
- The startup scripts?
- The user's home directory?

### The Map

```bash
ls -la /
```

Output:

```
drwxr-xr-x   root root  4096 Jun 30 10:00 bin
drwxr-xr-x   root root  4096 Jun 30 10:00 boot
drwxr-xr-x   root root  3480 Jul 01 08:15 dev
drwxr-xr-x   root root  4096 Jun 30 10:00 etc
drwxr-xr-x   root root  4096 Jun 30 10:00 home
lrwxrwxrwx   root root     7 Jun 30 10:00 lib -> usr/lib
drwxr-xr-x   root root  4096 Jun 30 10:00 media
drwxr-xr-x   root root  4096 Jun 30 10:00 mnt
drwxr-xr-x   root root  4096 Jun 30 10:00 opt
dr-xr-xr-x  root root     0 Jul 01 08:15 proc
drwx------   root root  4096 Jun 30 10:00 root
drwxr-xr-x   root root  4096 Jun 30 10:00 run
lrwxrwxrwx   root root     7 Jun 30 10:00 sbin -> usr/bin
drwxr-xr-x   root root  4096 Jun 30 10:00 sys
drwxrwxrwt   root root  4096 Jul 01 08:15 tmp
drwxr-xr-x   root root  4096 Jun 30 10:00 usr
drwxr-xr-x   root root  4096 Jun 30 10:00 var
```

### What Each Directory Does

| Directory | Purpose | Example |
|-----------|---------|---------|
| `/bin` | Essential user binaries | `ls`, `cp`, `cat`, `grep` |
| `/boot` | Kernel and boot files | `vmlinuz`, `grub` |
| `/dev` | Device files | `/dev/sda`, `/dev/null` |
| `/etc` | **System configurations** | `/etc/nginx/nginx.conf` |
| `/home` | User home directories | `/home/prathamesh` |
| `/lib` | Shared libraries | `.so` files |
| `/media` | Removable media mount | USB drives |
| `/mnt` | Temporary mount points | Manual mounts |
| `/opt` | Third-party software | `/opt/google/chrome` |
| `/proc` | **Virtual — live system info** | `/proc/cpuinfo`, `/proc/meminfo` |
| `/root` | Root user's home | `/root` |
| `/run` | Runtime data (PID files, sockets) | `/run/nginx.pid` |
| `/sbin` | System binaries (admin) | `iptables`, `reboot` |
| `/sys` | Virtual — kernel/device info | `/sys/class/net/` |
| `/tmp` | Temporary files (cleared on reboot) | Scratch space |
| `/usr` | User programs and libraries | `/usr/bin`, `/usr/local` |
| `/var` | **Variable data (logs, caches)** | `/var/log/syslog` |

### The 4 You'll Use Most

1. **`/etc`** — configs (nginx, docker, systemd)
2. **`/var/log`** — logs (syslog, auth, app logs)
3. **`/home`** — your stuff
4. **`/proc`** — live system info (CPU, memory, processes)

### Exercise 1

1. Run `ls -la /etc` — list config files
2. Run `ls -la /var/log` — list log files
3. Run `cat /etc/hostname` — what's your server's name?
4. Run `cat /proc/cpuinfo | head -20` — CPU info

## Part 3: Navigating with ls (15 min)

### The Problem

You need to find a file, but you don't know where it is. `ls` is your first tool.

### The Command

```bash
ls -la /path/to/directory
```

| Flag | What it does |
|------|--------------|
| `-l` | Long format (permissions, owner, size, date) |
| `-a` | Show hidden files (starting with `.`) |
| `-h` | Human-readable sizes (KB, MB, GB) |
| `-la` | Combine them — shows everything |

### Try It

```bash
ls -la ~
```

Output:

```
drwxr-xr-x  5 prathamesh prathamesh 4096 Jul 01 08:00 .
drwxr-xr-x  3 root       root       4096 Jun 30 10:00 ..
-rw-------  1 prathamesh prathamesh  220 Jun 30 10:00 .bash_history
-rw-------  1 prathamesh prathamesh 3526 Jun 30 10:00 .bashrc
drwxr-xr-x  2 prathamesh prathamesh 4096 Jul 01 08:00 Documents
drwxr-xr-x  3 prathamesh prathamesh 4096 Jul 01 08:00 projects
```

### Reading ls -l Output

```
-rw-r--r-- 1 prathamesh prathamesh 3526 Jun 30 10:00 .bashrc
│          │  │          │          │    │             │
│          │  │          │          │    │             └─ filename
│          │  │          │          │    └─ date/time
│          │  │          │          └─ size (bytes)
│          │  │          └─ group
│          │  └─ owner
│          └─ link count
└─ type + permissions
```

### Exercise 2

1. Run `ls -la /etc/ssh` — see SSH configs
2. Run `ls -la /var/log` — what log files exist?
3. Run `ls -la /proc/1` — what's PID 1? (hint: it's init/systemd)

## Part 4: Finding Files and Sizes (15 min)

### Finding Large Directories

The server is running out of disk. Where's the space going?

```bash
du -sh /*
```

| Flag | What it does |
|------|--------------|
| `-s` | Summary (total size per directory) |
| `-h` | Human-readable (1.2G, 500M, etc.) |

### Try It

```bash
du -sh /* 2>/dev/null
```

Output:

```
1.2G    /usr
800M    /var
400M    /home
200M    /opt
50M     /etc
...
```

### Find Large Files

```bash
find / -type f -size +100M 2>/dev/null
```

This finds all files larger than 100MB. Useful for finding what's eating disk.

### Identify File Types

```bash
file /etc/passwd
file /usr/bin/ls
file /var/log/syslog
```

Output:

```
/etc/passwd:   ASCII text
/usr/bin/ls:   ELF 64-bit LSB executable
/var/log/syslog: ASCII text
```

### Exercise 3

1. Run `du -sh /* 2>/dev/null` — what's the largest directory?
2. Run `find /var -type f -size +10M 2>/dev/null` — any large files in /var?
3. Run `file /usr/bin/bash` — what type of file is bash?

## Part 5: /proc — The Virtual Filesystem (10 min)

### The Problem

You need to check CPU info, memory usage, or running processes. `/proc` is where Linux exposes live system data.

### Key Files

| File | Shows |
|------|-------|
| `/proc/cpuinfo` | CPU details (model, cores, speed) |
| `/proc/meminfo` | Memory usage (total, free, cached) |
| `/proc/loadavg` | System load (1min, 5min, 15min averages) |
| `/proc/uptime` | How long the system has been running |
| `/proc/[pid]/` | Per-process info |

### Try It

```bash
# CPU info
cat /proc/cpuinfo | head -10

# Memory info
cat /proc/meminfo | head -10

# System load
cat /proc/loadavg

# Uptime
cat /proc/uptime
```

### Exercise 4

1. Run `cat /proc/cpuinfo | grep "model name"` — what CPU is this?
2. Run `cat /proc/meminfo | grep MemTotal` — how much RAM?
3. Run `cat /proc/loadavg` — is the system busy?
