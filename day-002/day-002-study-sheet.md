## Quick Reference — The 4 Directories You'll Use Most

| Directory | What's Inside | When You Use It |
|-----------|--------------|-----------------|
| `/etc` | Config files | "Where's the nginx config?" → `/etc/nginx/` |
| `/var/log` | Log files | "Where are the logs?" → `/var/log/syslog` |
| `/home` | User directories | "Where's my stuff?" → `/home/yourname` |
| `/proc` | Virtual — live system info | "How much RAM?" → `cat /proc/meminfo` |

## Key Commands Cheat Sheet

```bash
# Find what's eating disk space
du -sh /* 2>/dev/null

# Check RAM
cat /proc/meminfo

# Check CPU
cat /proc/cpuinfo

# Search for files containing a word (recursive)
grep -r "ssh" /etc/

# List all files including hidden
ls -la /path

# Find large files
find / -type f -size +100M 2>/dev/null
```

## `/proc` — Virtual Filesystem (NOT Real Files)

| File | Shows |
|------|-------|
| `/proc/cpuinfo` | CPU model, cores, speed |
| `/proc/meminfo` | RAM total, free, cached |
| `/proc/loadavg` | System load (1/5/15 min) |
| `/proc/uptime` | How long server has been running |
| `/proc/[pid]/` | Per-process info |

**Key fact:** `/proc` files are generated by the kernel in memory. They don't exist on disk.

---

## `/etc/passwd` vs `/etc/shadow`

| File | Contains | Permissions |
|------|----------|-------------|
| `/etc/passwd` | Username, UID, GID, home dir, shell | Readable by all |
| `/etc/shadow` | Passwords (hashed) | Root only |

**Remember:** `/usr/bin/passwd` is the **command** to change passwords, not the file.

---

## `df` vs `du`

| Command | What It Shows |
|---------|--------------|
| `df -h` | Filesystem disk usage (per partition) |
| `du -sh /*` | Directory disk usage (per folder) |

**Use `du` to find which directories are eating space.**
