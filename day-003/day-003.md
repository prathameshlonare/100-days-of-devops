# Day 3/100 — Linux Commands

> **Goal:** Master the essential Linux commands — navigate, search, filter, and chain them together. By the end, you'll build a commands cheat sheet and be able to find anything on a Linux system.

---

## Part 1: Why Commands Matter in DevOps (10 min)

Every DevOps tool runs on Linux. Docker runs on Linux. Kubernetes runs on Linux. Your CI/CD pipelines run on Linux.

You don't need to memorize every command. You need to know:
- Where to look
- How to search
- How to filter output

### What We'll Cover

| Command | What it does |
|---------|--------------|
| `ls`, `cd`, `pwd` | Navigate the filesystem |
| `mkdir`, `rm`, `cp`, `mv` | Create, delete, copy, move files |
| `cat`, `less`, `head`, `tail` | View file contents |
| `grep`, `find` | Search files and contents |
| `|`, `>`, `>>` | Chain commands, redirect output |

## Part 2: Navigation Commands (20 min)

### The Problem

You need to find a config file, check a log, or explore a directory. Navigation is your foundation.

### pwd — Where Am I?

```bash
pwd
```

Output: `/home/prathamesh`

This is your current directory. Always know where you are.

### cd — Move Around

```bash
cd /etc              # Go to /etc
cd ..                # Go up one directory
cd ~                 # Go to your home directory
cd -                 # Go back to previous directory
cd ../..             # Go up two directories
```

### ls — See What's Here

```bash
ls                  # Basic listing
ls -l               # Long format (permissions, size, date)
ls -la              # Show hidden files too
ls -lh              # Human-readable sizes
ls -ltr             # Sort by date (newest last)
```

| Flag | What it does |
|------|--------------|
| `-l` | Long format |
| `-a` | Show hidden (dot) files |
| `-h` | Human sizes (KB, MB) |
| `-t` | Sort by time |
| `-r` | Reverse order |

### Try It

```bash
# Navigate to /etc and list configs
cd /etc
ls -la

# Go home and list your files
cd ~
ls -la

# Go back to where you were
cd -
```

### Exercise 1

1. Run `pwd` — where are you?
2. Run `cd /var/log && ls -la` — list log files
3. Run `cd ~ && ls -la` — back home, list everything
4. Run `cd /proc/1 && ls -la` — explore PID 1

## Part 3: File Operations (15 min)

### mkdir — Create Directories

```bash
mkdir mydir                    # Create one directory
mkdir -p a/b/c/d              # Create nested directories
```

`-p` creates parent directories too. Without it, `mkdir a/b/c` fails if `a/b` doesn't exist.

### touch — Create Empty Files

```bash
touch file.txt                # Create empty file
touch file{1..5}.txt          # Create file1.txt through file5.txt
```

### cp — Copy

```bash
cp file.txt backup.txt            # Copy file
cp -r mydir/ mydir-backup/        # Copy directory (recursive)
```

### mv — Move or Rename

```bash
mv file.txt /tmp/             # Move to /tmp
mv oldname.txt newname.txt    # Rename
```

### rm — Delete

```bash
rm file.txt                   # Delete file
rm -r mydir/                  # Delete directory and contents
rm -rf mydir/                 # Force delete (no confirmation)
```

**WARNING:** `rm -rf` has no undo. Triple-check before running it.

### Try It

```bash
# Create a test directory
mkdir -p ~/test-commands
cd ~/test-commands

# Create some files
touch file1.txt file2.txt file3.txt

# Copy file1
cp file1.txt file1-backup.txt

# Rename file2
mv file2.txt renamed-file.txt

# List everything
ls -la

# Clean up
cd ~
rm -rf ~/test-commands
```

### Exercise 2

1. Create `~/practice/` directory
2. Create 5 files inside it
3. Copy one file to a new name
4. Rename another file
5. Delete all files and the directory

## Part 4: Viewing Files (15 min)

### cat — Dump Entire File

```bash
cat /etc/hostname         # View file contents
cat -n /etc/hosts         # With line numbers
```

Good for small files. Bad for large files (dumps everything).

### head — First Lines

```bash
head /var/log/syslog          # First 10 lines
head -20 /var/log/syslog      # First 20 lines
```

### tail — Last Lines

```bash
tail /var/log/syslog          # Last 10 lines
tail -20 /var/log/syslog      # Last 20 lines
tail -f /var/log/syslog       # Follow in real-time (Ctrl+C to stop)
```

`tail -f` is your best friend for watching logs in real-time.

### less — Page Through Files

```bash
less /var/log/syslog
```

- Space = next page
- `b` = previous page
- `/text` = search for "text"
- `q` = quit

### Try It

```bash
head -5 /etc/passwd
tail -5 /etc/passwd
cat -n /etc/hostname
```

### Exercise 3

1. Run `head -20 /var/log/syslog` — first 20 log lines
2. Run `tail -5 /etc/passwd` — last 5 users
3. Run `cat -n /etc/hosts` — see hosts with line numbers

## Part 5: Searching with grep and find (20 min)

### grep — Search File Contents

```bash
grep "error" /var/log/syslog          # Find lines with "error"
grep -i "error" /var/log/syslog       # Case-insensitive
grep -r "error" /var/log/             # Search all files in directory
grep -n "error" /var/log/syslog       # Show line numbers
grep -c "error" /var/log/syslog       # Count matches
grep -v "info" /var/log/syslog        # Invert — exclude lines with "info"
```

| Flag | What it does |
|------|--------------|
| `-i` | Case-insensitive |
| `-r` | Search recursively (all files) |
| `-n` | Show line numbers |
| `-c` | Count matches |
| `-v` | Invert (exclude) |

### find — Find Files by Name/Type

```bash
find . -name "*.py"                    # Find .py files in current dir
find / -name "*.log" 2>/dev/null      # Find all .log files on system
find . -type f -size +100M             # Find files larger than 100MB
find . -mtime -7                       # Modified in last 7 days
find . -empty                          # Find empty files/dirs
```

| Flag | What it does |
|------|--------------|
| `-name` | Match filename pattern |
| `-type f` | Files only |
| `-type d` | Directories only |
| `-size` | By size (+100M = larger than 100MB) |
| `-mtime` | Modified time (-7 = last 7 days) |

### Try It

```bash
# Search for "root" in /etc/passwd
grep "root" /etc/passwd

# Find all .conf files in /etc
find /etc -name "*.conf" 2>/dev/null

# Find large files
find / -type f -size +50M 2>/dev/null | head -10
```

### Exercise 4

1. Run `grep "root" /etc/passwd` — find root user entry
2. Run `find /etc -name "*.conf" 2>/dev/null | wc -l` — count config files
3. Run `grep -r "listen" /etc/nginx/ 2>/dev/null` — find nginx listen directives

## Part 6: Pipes and Redirection (10 min)

### The Pipe `|` — Chain Commands

The pipe takes output of one command and feeds it as input to the next.

```bash
# List all files, then grep for .conf
ls -la /etc | grep ".conf"

# Find all processes, then grep for nginx
ps aux | grep nginx

# Count how many users exist
cat /etc/passwd | wc -l
```

### Redirect `>` and `>>`

```bash
# Overwrite file with output
ls -la /etc > etc-list.txt

# Append to file (don't overwrite)
echo "new line" >> etc-list.txt
```

### Try It

```bash
ls -la /etc | grep ".conf" | head -10
cat /etc/passwd | grep "bash" | wc -l
```

### Exercise 5

1. Run `ps aux | grep bash` — find bash processes
2. Run `du -sh /* 2>/dev/null | sort -rh | head -5` — top 5 largest directories
3. Run `cat /etc/passwd | grep "/home" | wc -l` — count home directories

## Part 8: Recap (5 min)

### What You Learned

| Command | Use Case |
|---------|----------|
| `ls -la` | See everything in a directory |
| `cd`, `pwd` | Navigate |
| `mkdir`, `touch`, `cp`, `mv`, `rm` | File operations |
| `cat`, `head`, `tail` | View files |
| `grep -r` | Search file contents |
| `find . -name` | Find files by name |
| `|` pipe | Chain commands |

### The Pattern

When you need to find something:
1. `ls -la /path` — see what's there
2. `grep -r "text" /path` — search contents
3. `find /path -name "*.ext"` — find by name
4. `du -sh /path/*` — check sizes
